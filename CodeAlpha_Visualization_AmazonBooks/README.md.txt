# CodeAlpha Task 3 — Data Visualization

## 📌 Project Overview
This project visualizes the Amazon Bestselling Books dataset created in Task 1.
Different charts and graphs were used to understand price trends, rating
patterns, and book popularity.

## 📈 Visualizations Included
- Price distribution
- Rating distribution
- Price vs Rating scatter plot
- Top 10 most expensive books
- Rating count visualization

## 🛠 Tools Used
- Python
- Matplotlib
- Seaborn
- Pandas
